---
name: Muhurat matching authority
description: Safety boundary between catalogue-reviewed auspicious windows and a Pandit's unconfirmed calendar.
---

Dated Pandit matching must accept only a Puja/date/window combination that the server can resolve to a published catalogue Muhurat record. A matching result may explain ritual, location, language, and tradition eligibility, but must label the Pandit's calendar as requiring confirmation.

**Why:** A syntactically valid date or a computed free-form Panchang result is not enough to claim that a window belongs to a reviewed Puja catalogue, and a qualified Pandit is not necessarily free on that date.

**How to apply:** Require an authoritative Puja reference for dated directory searches, reject forged, stale, or mismatched windows server-side, and keep booking availability language explicitly provisional until a real calendar source confirms it.
