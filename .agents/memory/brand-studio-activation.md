---
name: Brand Studio activation
description: Compatibility boundary between legacy branding and configurable unified branding.
---

Keep legacy header, drawer, and footer branding active until an Admin changes a branding-specific control. Saving unrelated Site Settings must preserve the legacy treatment.

**Why:** Automatically activating unified branding during a contact, analytics, or other unrelated settings save can unexpectedly change established branding and create contrast problems.

**How to apply:** Any future branding fields should participate in explicit brand activation. Non-brand Site Settings updates must preserve the current activation state.
