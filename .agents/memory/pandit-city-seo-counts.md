---
name: Pandit city SEO counts
description: How city-page descriptions and headers should represent live Pandit availability without overstating indexed profiles.
---

City-page availability counts must come from the live public directory result, not only from the SEO projection's indexed provider list. The projection can intentionally omit eligible profiles whose profile content is not yet indexable, which otherwise makes a useful city page claim zero while the directory lists Pandits.

**Why:** SEO/indexability is a publishing decision, while directory availability is a user-facing supply decision; they are related but not interchangeable.

**How to apply:** Keep structured ItemList/profile claims limited to indexed providers, but pass the live directory total separately into city metadata and visible availability copy.
