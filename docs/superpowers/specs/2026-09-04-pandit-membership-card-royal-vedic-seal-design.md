# Pandit Membership Card — Royal Vedic Seal

## Goal

Redesign the digital and printable Pandit lifetime membership card as a clean, premium Vedic credential. Remove the random dotted texture, oversized temple drawing, mandala, map silhouette, and other decorative marks that currently compete with the Pandit’s identity.

## Visual Direction

Use a deep-maroon base with restrained antique-gold embossing. The card should feel ceremonial and authoritative without becoming ornate. Depth comes from subtle tonal gradients, a fine double-line gold border, controlled highlights, and shallow embossed or debossed treatments—not background patterns.

## Front

- Small embossed Vedic Tatva lotus seal and wordmark.
- Discreet verified-Pandit status treatment.
- Professionally framed Pandit portrait.
- Pandit name as the strongest personalized element.
- Specialization, registration number, and city/state beneath it.
- Restrained “Lifetime Membership” designation.
- No dotted texture, temple illustration, mandala, map, random symbols, or visual clutter.

## Back

- Small Vedic Tatva seal and credential title.
- Short official certification statement.
- Clearly grouped embossed fields for Pandit name, registration number, specialization, and location.
- High-contrast QR code with a concise “Scan to verify” label.
- Verification path and website in a quiet footer.
- No decorative pattern behind the QR code or text.

## Dynamic Data

Continue using the approved profile data already passed to the card:

- Portrait
- Pandit name
- Specialization
- Registration number
- City and state
- Verified/inactive status
- Public verification URL and QR code

Long names and specializations must remain legible through responsive type sizing and safe truncation rather than overlapping other fields.

## Interaction and Output

Preserve:

- Front/back flip control
- Copy and share verification link
- PNG download
- PDF download
- Print layout
- Accessible card and control labels
- Reduced-motion support

Both faces must render correctly in browser capture and print without relying on unsupported blend modes or noisy textures.

## Acceptance Criteria

1. No random dots, marks, mandala, temple line art, or map silhouette remain.
2. Both sides use one coherent maroon-and-antique-gold design system.
3. Pandit details look embossed and remain clearly readable.
4. QR verification remains functional and visually isolated.
5. Front/back flipping, downloads, sharing, and printing continue to work.
6. The card remains responsive at mobile and desktop widths.
7. The final result is visually checked in the running Pandit portal or public verification page.
